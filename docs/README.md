# docs/

- [mods.md](mods.md): every mod, its API and its off switch.
- [changes/](changes/README.md): every change vs stock Tempo, one entry per mod or tool. Its screenshots and clips are not in this repo; their captions are kept as text. There is also an HTML view in `changes/index.html`. Both are generated by `node docs/changes/build.mjs --no-media`.
- [modding-guide.md](modding-guide.md): where the editable code lives and how to write a mod.
- [reverse-engineering.md](reverse-engineering.md): how Tempo 0.0.121 is built (architecture, IPC, network, AI), from static analysis.
- [dynamic-analysis.md](dynamic-analysis.md): what was confirmed with the app running (bridges, webPreferences, CSP, domains).
- `chan_*.txt`: the IPC channel names, one file per process or preload.
- [qa/01-documentation-research.md](qa/01-documentation-research.md): Tempo's features according to its public docs and changelog.
- [qa/02-feature-inventory.md](qa/02-feature-inventory.md): every screen and feature, mapped to selectors and IPC.
- [qa/03-harness.md](qa/03-harness.md): the QA harness (isolation, ports, logged-in profiles).
- [qa/10-shell.md](qa/10-shell.md), [qa/30-settings.md](qa/30-settings.md): suite results for the shell and Settings. The raw Settings dump is in `qa/evidence/settings/`.
